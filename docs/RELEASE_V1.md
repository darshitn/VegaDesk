# VEGA Desk 0.1.0-beta.1

The first published version is a personal-use Windows beta. Its release journey is open the app, create and complete a task, set a timer or reminder, receive an alert, resume a project, quit and restart with state intact.

## Fixed release scope

- Existing tasks, notes, timers, reminders, focus, projects and coursework.
- Readable sci-fi and Glass themes, usable compact window, visible startup and explicit Quit.
- Existing safe app/site launch tools with truthful evidence.
- Optional existing local voice and model integrations, with readiness and limitations visible. Custom Hey Vega training stays paused.
- Existing policy/executor/provider boundaries remain extension points for future features.

## Three delivery stages

1. Release corrections and canonical packaging. Finish when startup, onboarding, voice settings and packaging use consistent contracts.
2. Build and verify an isolated release candidate. Finish with source manifest, artifact checksum, backend readiness, preserved data, representative core actions and process teardown evidence.
3. Publish the verified personal beta. Finish with downloadable artifacts, a short owner walkthrough and explicit hardware/signing limitations.

At initialization, stage 1 is active and stages 2–3 remain. Stage completion requires measured evidence. The study card and broader companion remain separate follow-up work.

## Preservation and distribution

Existing edits, personal data, credentials, recordings, models and build directories are preserved. New builds use a unique release directory. Private local assets are excluded from the source snapshot and installer. No automatic model downloads or paid inference are part of setup.

## Extensibility

Keep React surfaces and backend action contracts separate. Future capabilities should reuse typed tool proposals, policy decisions, executors, receipts and shared backend state. UI effects follow committed results. Speech interruption and action-job cancellation remain distinct concepts.
