# Core productivity and execution foundation

## Purpose and behavior
Use persistent tasks, timers, reminders, focus, workspaces and bounded tools.

## Flow and responsibilities
Text/voice enters the backend; deterministic handlers run first. Optional models propose actions through the registry and policy. React refreshes committed productivity changes.

## Decisions and trade-offs
Reuse the existing Electron, React, FastAPI and SQLite application. Historical motivation is documented in the brief; this review does not establish every original decision.
